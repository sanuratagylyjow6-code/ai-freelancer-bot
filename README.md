# 🤖 AI Freelancer Bot

Telegram-бот, который генерирует и выполняет код через Gemini API.

## Команды

- /start — регистрация
- /help — справка
- /parse — спарсить цитаты
- /mystats — статистика
- /clients — клиенты
- /code <задание> — сгенерировать код
- /run <задание> — сгенерировать + выполнить
- /history — история задач

## Технологии

Python 3, pyTelegramBotAPI, Google Gemini, SQLite
